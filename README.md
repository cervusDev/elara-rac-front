# Elara RAC - Frontend

Este repositório contém o APP do sistema Elara RAC.

## ▶️ Rodando em Ambiente Local

Para executar o projeto localmente, siga os passos abaixo:

No diretório raiz do projeto, execute o seguinte comando:

```
npm i
```
depois:
```bash
npm run dev
```
